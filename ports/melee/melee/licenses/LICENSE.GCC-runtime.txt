melee.aarch64 statically links the GCC 12.3.0 runtime libraries libstdc++.a and libgcc.a from the
Bootlin aarch64--glibc--stable-2023.08-1 toolchain (a copy of that toolchain whose sysroot carries
glibc 2.30 is used for the release link; native/tools/glibc230_toolchain.sh). libstdc++.a is
modified: one object (native/tools/glibc_compat.c, this port's own code) is added so the archive
resolves two symbols that glibc 2.30 lacks. The Flip bundle variant ships the unmodified
libstdc++.so.6.0.30 instead.
