## Controls

| Button | Action |
|--|--| 
|DPAD / Left Stick|Movement|
|A|Jump|
|B|Fly|
|Y|Change form|
|X|Shoot|
|L1/R1|Change weapon|
|Start|Menu|
|Select|Upgrades menu|
