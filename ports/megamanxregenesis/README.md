## Notes

This game comes shiped with a preconfigured save file in save slot 1. It is set on hunter difficulty with default controls as well as lighting effects and partical effects turned off. If you wish to make a new or add a save file I HIGHLY recommend that you turn lighitng and partical effects off for the best experience.

Special thanks to the amazing Mega Man X Regenesis team for creating such an amazing fan made game and keeping the legacy of fan made Mega Man games going.

## Controls

| Button | Action |
|--|--| 
|dpad|movement|
|left analog stick|movement|
|A|Dash|
|B|Jump|
|Y|Shoot|
|X|Secondary|
|R1|Next Weapon/Menu Right|
|L1|Previous Weapon/Menu Left|
|Start|Pause/Menu|
|Select|Key K|
|R2|Key U|
|L2|Key G|
