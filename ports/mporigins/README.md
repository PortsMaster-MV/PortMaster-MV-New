## Controls

|Button|Action|
|-|-|
|DPAD / Left Stick|Movement|
|Right Stick|Aim (optional)|
|A|Confirm / Jump|
|B|Morph Ball|
|X|Shoot|
|Y|Missile|
|L1|Free Aim / Boost Ball|
|R1|Aim-Lock / Spider Ball|
|L2|Scan Visor|
|R2|Grapple Beam|
|Select|Map|
|Start|Menu|
