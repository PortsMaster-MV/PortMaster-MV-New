Star Fox Enhanced is a fan-made enhancement/reimplementation built on top of
the original 1993 Star Fox / Starwing SNES game (presented by Nintendo,
developed by Argonaut Software) and the Star Fox EX and UltraStarFox
community projects. See that project's CREDITS.md for the full attribution
list:

    https://github.com/kandowontu2/starfox-enhanced/blob/main/CREDITS.md

As of the pinned commit, the starfox-enhanced repository does not carry an
explicit top-level open-source license for its own original code (its
README points only to CREDITS.md and THIRD_PARTY_NOTICES.md for the
libraries it bundles -- see the other LICENSE.*.txt files in this folder
for those). This notice is provided for attribution; it does not assert a
license starfox-enhanced itself has not granted.

No Nintendo ROM data, assets, or other copyrighted game content are
included in this port. The end user must supply their own legally obtained
Star Fox/Starwing .sfc or .smc ROM, which the runtime validates locally and
never distributes.
