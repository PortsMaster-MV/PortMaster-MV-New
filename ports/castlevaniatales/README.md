## Controls

| Button | Action |
|--|--| 
|dpad|movement|
|left-analog|movement|
|Start|Pause/Resume|
|A button|Shield/Holy Power|
|B button|Jump|
|Y button |Attack/Weapon|
|Y + Up Combo|Special Weapon|
|X button|Switch Sub Weapons|
|L1|Backwards Dash|
|R1|Block|
